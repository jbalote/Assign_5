Page 5: Introduction to Linear Functions

Function Rule

A function gives exactly one output for each input.

Slope-Intercept Form

f(x) = mx + b where m is slope and b is y-intercept.

Input and Output

Replace x with a value to compute the function output.

Lecture Notes

  • In f(x), x is the input and f(x) is the output value.
  • The coefficient m controls steepness; b shifts the graph up or down.
  • Function notation is another way to write y-values generated by a rule.
f(x) = 2x + 1, f(3) = 7
